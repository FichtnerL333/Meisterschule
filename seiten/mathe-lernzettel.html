Lernzettel Mathematik

Brüche, Wurzeln, quadratische Gleichungen, Funktionen und Trigonometrie, mit den erlaubten Formeln für die SA.

Themen im Skript

  1. Bruchrechnen: multiplizieren (Zähler · Zähler, Nenner · Nenner), dividieren (mit dem Kehrwert malnehmen), Ergebnis kürzen.
  2. Wurzeln: √a · √b = √(a·b), teilweise Wurzel ziehen (√18 = 3√2), Nenner rational machen.
  3. Quadratische Gleichungen ax² + bx + c = 0: - ohne c: x ausklammern → x(ax + b) = 0. Ohne b: nach x² auflösen, Wurzel ziehen. - allgemein: x₁,₂ = (−b ± √(b² − 4ac)) / 2a. Diskriminante D = b² − 4ac: D > 0 zwei Lösungen, D = 0 eine, D < 0 keine.
  4. Lineare Funktionen f(x) = m·x + t: m = Steigung (m > 0 steigt, m < 0 fällt, m = 0 waagrecht), t = y-Achsenabschnitt. Steigung aus zwei Punkten: m = (y₂ − y₁) / (x₂ − x₁).
  5. Quadratische Funktionen f(x) = ax² + bx + c (Parabel): a > 0 nach oben offen, a < 0 nach unten. Scheitelpunktform f(x) = a(x − xs)² + ys. Nullstellen mit der Formel oben.

Trigonometrie (Formelsammlung im Heft)

  • Rechtwinkliges Dreieck: sin = Gegenkathete/Hypotenuse, cos = Ankathete/Hypotenuse, tan = Gegenkathete/Ankathete. Merkhilfe: s c t / G A G / H H A.
  • Sinussatz (beliebiges Dreieck): a / sin α = b / sin β = c / sin γ.
  • Kosinussatz: a² = b² + c² − 2bc · cos α. Winkel: cos γ = (a² + b² − c²) / (2ab).
  • Im Heft durchgerechnete Aufgaben mit Höhen, Steigungen in Prozent und schiefwinkligen Dreiecken (Buch S. 14 und 22).

Noch offen: Im Heft steht beim Kosinussatz „a² = b² + c² − 2·a·c·cos α“. Richtig ist 2·b·c. Bitte im Heft korrigieren.
