Auch genannt polares Anhängen Übertragung / Absteckung
Praxis neue Punkte elektronisch einmessen (Tachymeter misst Winkel + Strecke) und in Koordinaten umrechnen bekannte Punkte (Grenzsteine, Gebäudeecken), die nicht mehr sichtbar sind, wieder in der Örtlichkeit abstecken

Formeln

  • Vermessung rechnet in gon (Vollkreis = 400 gon, rechter Winkel = 100 gon). Umrechnung: φ in Grad / 0,9 = φ in gon.
  • Achsen: x nach Norden (Abszisse), y nach Osten (Ordinate), Winkel im Uhrzeigersinn ab x.
  • 1. Grundaufgabe: Δy = s · sin φ, Δx = s · cos φ → y₂ = y₁ + Δy, x₂ = x₁ + Δx.
  • 2. Grundaufgabe: s = √(Δx² + Δy²), φ = tan⁻¹(Δy / Δx).
  • Quadrant beachten: Der Taschenrechner kennt nur −100…+100 gon. Merke aus dem Heft: Wenn Δx negativ ist, immer + 200 gon. Ist Δx positiv und Δy negativ, + 400 gon.
  • Beispiel aus dem Heft: Δx = −20, Δy = −30 → tan⁻¹(1,5) = 62,5666 gon + 200 = 262,5666 gon. Δx = +20, Δy = −30 → −62,5666 + 400 = 337,4334 gon.

Winkel umrechnen (Skript S. 20)

  • gon → Grad: · 0,9 · Grad → gon: : 0,9 (400 gon = 360°). Beispiele: 60 gon = 54°, 72° = 80 gon, 32° = 35,56 gon.
  • Grad-Minuten-Sekunden → Dezimal: Grad + Min/60 + Sek/3600. 6°34'47" = 6,5797°, 12°16'23" = 12,2731°.
  • Dezimal → Grad-Minuten-Sekunden: Nachkommastellen · 60. 25,97854° = 25°58'43". 25,350 gon = 22,815° = 22°48'54".

Orthogonalverfahren (Rechtwinkelverfahren)

  • Klassische Methode der Katastervermessung. Punkte werden rechtwinklig zu einer Messungslinie eingemessen.
  • Messungslinie = Achse zwischen zwei gut sichtbaren Punkten (= x-Achse/Abszisse), z. B. von P23 (0,00) nach P25 (52,48).
  • Abszisse (x-Wert): Strecke auf der Messungslinie bis zum Lotfußpunkt. Ordinate (y-Wert): senkrechter Abstand vom Lotfußpunkt zum Punkt.
  • Umgekehrt geht auch Absteckung mit vorgegebenen Maßen.

Standpunkt P1 (y 529,82; x 710,07), gemessen zu P3: φ = 14,7069 gon, s = 83,55 m. - φ in Grad: 14,7069 · 0,9 = 13,2362° - Δy = sin φ · s = 19,13 m → y₃ = 529,82 + 19,13 = 548,95 m - Δx = cos φ · s = 81,33 m → x₃ = 710,07 + 81,33 = 791,40 m - Ergebnis P3 (548,95; 791,40) ✓ (damit ist die frühere offene Frage zu diesem Beispiel erledigt)

Flächenberechnung mit Koordinaten (Gauß'sche Trapezformel, Heft 16.11.2026)

  • Verfahren aus der Geodäsie, um die Fläche von unregelmäßigen Vielecken aus ihren Koordinaten zu rechnen. Besonders nützlich für Grundstücke.
  • Formel: 2F = Σ xᵢ · (yᵢ₊₁ − yᵢ₋₁), also jeder x-Wert mal (y vom nächsten Punkt − y vom vorigen Punkt). Am Ende durch 2.
  • Tabellen-Methode („über Kreuz“): Punkte untereinander schreiben, ersten Punkt unten wiederholen. Spalte 1 = x · y vom nächsten Punkt, Spalte 2 = y · x vom nächsten Punkt. 2F = Σ Spalte 1 − Σ Spalte 2.
  • Beispiel 1: Viereck mit P1 (x 6; y 2), P2 (10; 5), P3 (7; 9), P4 (3; 6) → 168 − 118 = 50 → F = 25 m² ✓
  • Beispiel 2: Fünfeck A–E → 2F = 248,9 − (−16,89) = 265,79 → F ≈ 132,9 m² ✓
  • Vorzeichen: Kommt eine negative Fläche raus, wurde nur andersherum gezählt. Dann den Betrag nehmen.
