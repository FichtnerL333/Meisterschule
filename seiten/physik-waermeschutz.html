6. Wärmeschutz

Formeln | Größe | Formel | Einheit | |---|---|---| | Wärmedurchlasswiderstand einer Schicht | R = d / λ (d in m, λ = Wärmeleitfähigkeit) | m²K/W | | ganzes Bauteil (mehrere Schichten) | ΣR = R₁ + R₂ + … | m²K/W | | Wärmedurchgangswiderstand | R_T = R_si + ΣR + R_se | m²K/W | | Wärmedurchgangskoeffizient | U = 1 / R_T | W/(m²K) | | flächenbezogene Masse | m' = d · ρ | kg/m² | | Wärmeeindringkoeffizient | b = √(λ · ρ · c) | Ws/(m²K s^0,5) | | Temperaturleitzahl | a = λ / (ρ · c) | m²/s | | Wärmespeicherfähigkeit | Q = m' · c · Δθ | Ws/m² | | Temperaturamplitudenverhältnis / -dämpfung | TAV = Δθ_si / Δθ_se · TAD = 1 / TAV | – | | Wärmestromdichte | q = U · (θ_i − θ_e) | W/m² |

Wärmeübergangswiderstände (DIN EN ISO 6946): Wärmestrom horizontal (senkrechte Außenwand): R_si = 0,13, R_se = 0,04. Aufwärts: 0,10 / 0,04. Abwärts: 0,17 / 0,04. Dach mit Neigung ≥ 60° zählt als horizontal, < 60° als aufwärts.

Merksätze - R_si/R_se: Widerstand der dünnen Luftschicht direkt an der Oberfläche. Wind und Richtung des Wärmestroms spielen mit. - U-Wert: wie viel Watt pro m² bei 1 K Unterschied durchgehen. Kleiner = besser gedämmt. Bei Fenstern wird direkt der U-Wert angegeben. - Spezifische Wärmekapazität c: Wärme, um 1 kg um 1 K zu erwärmen (Beton 1000, Holz 2100, Wasser 4200 Ws/kgK). - Großes b (Beton) = Boden fühlt sich kalt an. Kleines b (Holz) = fühlt sich warm an. - Temperatur wandert in Beton etwa 8-mal schneller als in Holz. - Viel Speichermasse dämpft Hitze im Sommer und hält Wärme im Winter. TAV = 0,05 heißt: Innen kommen nur 5 % der Schwankung von außen an.

Zusatzdämmung EPS (WLG 036): ΔR = 1,2 − 0,587 ≈ 0,61 → d = ΔR · λ = 0,61 · 0,036 = 0,022 m → gewählt 3 cm. Kontrolle: 0,587 + 0,03/0,036 = 1,42 > 1,2 ✓ 4. Nötig: R_T = 1/0,24 = 4,167 → ΔR_T = 3,41 → d = 3,41 · 0,036 = 0,123 m → gewählt 14 cm → R_T neu = 4,646 → U neu = 0,215 W/(m²K) ✓

6b. Temperaturverlauf / Schichtgrenztemperaturen

  • Formel: θ_neu = θ_vorher − (R_Schicht / R_T) · (θ_i − θ_e). Zuerst θ_si (mit R_si), dann Schicht für Schicht nach außen. Die letzte Rechnung muss wieder θ_e ergeben (Probe).
  • R_si = 0,13 und R_se = 0,04 (Wärmestrom waagrecht, Schneider Tafel 10.4).
  • Beispiel 1 (Wand aus 6., R_T = 0,757, 20 °C / −5 °C): θ_si 15,707 · θ_1/2 14,056 · θ_2/3 −3,018 · θ_se −3,679 · θ_e −5,000 °C. Alles nachgerechnet, stimmt.
  • Beispiel 2 (zweischalige Wand: 1,5 cm Innenputz λ 0,70 · 17,5 cm Kalksandstein λ 0,99 · 12 cm Dämmung λ 0,035 · 11,5 cm Klinker λ 0,96): ΣR = 3,747, R_T = 3,917 m²K/W. θ_si 19,170 · 19,034 · 17,905 · −3,977 · θ_se −4,742 · θ_e −4,997 °C (≈ −5, Rundung). Stimmt.
  • Merke: Fast der ganze Temperatursturz passiert in der Dämmung. Innen bleibt die Wand warm.

6c. Weiter mit Beispiel 2

  • Mindestwärmeschutz (Schneider Tafel 10.8, schweres Bauteil): R_min = 1,20 m²K/W. Vorhanden R = 3,747 > 1,20 → Nachweis erbracht. Wichtig: Hier mit R rechnen, ohne R_si und R_se!
  • GEG (Tafel 10.16): U_max = 0,24. Vorhanden U = 1 / 3,916 = 0,255 > 0,24 → nicht erbracht. Nötig R_T = 1 / 0,24 = 4,167 → fehlen 0,251 → d = 0,251 · 0,035 = 0,0088 m → ca. 1 cm mehr Dämmung.
  • Temperatur bei 2/3 der Dämmung (Wärmestrombilanz, Schneider S. 10.6): Bis zum Punkt ΣR_zu = 0,13 + 0,015/0,70 + 0,175/0,99 + ⅔ · 0,12/0,035 = 2,614. Ab dem Punkt bis außen ΣR_ab = 3,916 − 2,614 = 1,303.
  • Formel: θ = (θ_innen · ΣR_ab + θ_außen · ΣR_zu) / (ΣR_zu + ΣR_ab)
  • θ = (20 · 1,303 + (−5) · 2,614) / 3,916 = 3,32 °C. Zeichnerisch geht es auch: Punkt im Temperaturdiagramm ablesen.

6d. Formelsammlung Wärme

  • Wärmestromdichte q = U · (θ_i − θ_e) = (θ_i − θ_e) / R_T in W/m²
  • Wärmestrom Φ = q · A in W · Wärmemenge Q = q · A · t in Ws = J (1 kWh = 3,6 MJ)
  • Schichtgrenztemperaturen: θ_si = θ_i − R_si · q, dann jede Schicht θ_neu = θ_vorher − R_Schicht · q, am Ende θ_e = θ_se − R_se · q (Kontrolle).
